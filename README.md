# **Функциональность**
- **read_json** - Функция реализует чтение **json** файла
- **object_from_json** - Функция для создания объекта классов
- В модуле products.py объявлены два класса:
- **class Product** - Класс для представления продукта
- **class Category** - Класс для подсчета количества продуктов
- В данных классах используются декораторы **@property**, **@classmethod**, **@price.setter**
- Так же в классах используются магические методы такие как:```__init__ , __str__ , __add__```
- Добавлены отдельные модули под классы-наследники(```Smartphone и LawnGrass```)
- Прописаны функции **isinstance()** и **type()**, для реализации ограничений.
- Добавлен Абстрактный класс(```BaseProduct```) и Класс-Миксин(```ProductMixin```)
- Введена функциональность над исключениями,такими как: ```ZeroDivisionError```, ```ValueError```, ```TypeError```
